# Wr-Type-Dx7.sf2
【音色简介】  灵感来源于 Yamaha MODX m7 的 "Wr typedeck" 音色 与 Yamaha DX7 的经典电钢音色。 使用 DEXED（DX7 FM 合成器）进行音色调制， 经三层力度单音采样，逐键映射至完整 88 键。  低力度下温暖柔和，高力度下晶莹闪亮； 高音区略有畸变，但实际演奏中极少触及该音区。 希望这款音色能带给创作者 复古而又新颖的味道。  技术规格 - 音源引擎：DEXED（DX7 FM 合成器仿真） - 力度分层：3 层 - 采样范围：88 键全键域，逐键单音采样 - 创作时间：2026.10.11 17:57Not for commercial use.
